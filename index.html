Field notes: batch-downloading images, PDFs, and media in Chrome

Working notes on collecting many files from a page, open tabs, or a pasted URL list without clicking each link.

Short workflow

  1. Open the gallery, docs page, or media index you need.
  2. Scan for downloadable links; filter by type, extension, URL, or link text.
  3. Preview images if helpful, then save as files, a ZIP, or into a folder.
  4. Retry failed downloads a few times before chasing leftovers by hand.
