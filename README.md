# Field notes: batch-downloading files from Chrome pages

Working notes on pulling many images, PDFs, documents, and media links from a page (or a list of tabs / URLs) without clicking every link by hand.

## What this is for

Designers, researchers, and ops folks often need a local copy of assets shown on a gallery, docs portal, or media index. Doing it one-by-one is slow and easy to miss files.

## Workflow that worked for me

1. Open the page (or the set of tabs / URL list) that holds the files you need.
2. Scan for downloadable links by type, extension, URL pattern, or link text.
3. Preview images when useful, then save as separate files, one ZIP, or into a chosen folder.
4. Let failed downloads retry a few times before you chase them manually.
